# 第二章逻辑与精读方法

更新日期：2026-10-30。用途：用户亲自精读文献（清单见 [16-文献总表](16-文献总表.md)），再由本人的精读卡重建第二章。[13-第二章逐节确认稿](13-第二章逐节确认稿.md)保留作对照；其中变量归纳依据摘要整理，需用精读结果替换或修正。

## 一、整体逻辑

```
精读每篇 → 精读卡（理论框架 / 自变量·因变量·结论）
        → 第二章：理论基础 + 三问题的实证 + 变量汇总 + 缺口
        → 初步理论框架（自己的）
        → 第三章：从框架中选出要检验的关系 → 子问题 → 方法
        → 形成性调研修正框架 → 原型 → 预实验 → 正式比较 → 修订框架
```

## 二、第二章结构

| 节 | 回答什么 | 主要文献（清单编号） |
|---|---|---|

## 三、精读卡模板

先判断文献类型，再填对应字段。只有实验类研究才有严格意义的自变量和因变量。其他类型提供的是概念、机制、主题或设计维度，不能硬套变量。

**共同字段**：题录；类型；对应哪个问题（留什么／怎么留／怎么用）；一句话结论；对我的设计意味着什么；不适用的情况。

| 类型 | 需要提取的内容 |
|---|---|
| 实验／准实验 | 研究问题或假设；被试（人数、人群）；自变量及其水平；因变量及测量方式；控制了什么；主要结果（方向、是否显著）；局限 |
| 理论／模型 | 核心概念；模型结构（各部分如何关联）；证据从哪来；可推出的设计要求 |
| 质性／实地研究 | 对象与情境；方法（访谈、日记、部署时长）；主要主题；设计启示 |
| 设计／系统研究 | 设计目标；系统做了什么；评估方式与结果；可借鉴的设计维度 |
| 综述 | 覆盖范围；分类框架；指出的缺口 |

精读卡存放于 `literature/reading/`，每篇一个文件，文件名使用清单编号，例如 `02-van-den-hoven.md`。

## 四、2.6 变量汇总表（读完后填写）

| 文献 | 自变量／比较条件 | 因变量 | 调节或情境因素 | 测量方法 | 结论 |
|---|---|---|---|---|---|
| | | | | | |

归纳时把因变量分开写，不要合并：观看意愿、回忆是否发生、细节数量、准确性、情感与意义、使用负担。“个人习惯”在多数研究里是调节因素，不是自变量。

## 五、第三章的对应方式（候选，待第二章完成后确定）

| 子问题 | 性质 | 可能的自变量 | 可能的因变量 | 适合的方法 |
|---|---|---|---|---|
| RQ1 留什么 | 探索性，找出关键线索 | 线索类型 | 回忆是否发生、细节 | 个人材料回看 + 访谈（照片诱导），日记研究 |
| RQ2 怎么留 | 探索与设计试用 | 记录方式、形式 | 线索是否留下、负担与接受度 | 记录试用、共创工作坊 |
| RQ3 怎么用 | 比较检验 | 材料组织方式 | 观看意愿、回忆细节、准确性 | 原型对照实验 + 访谈 |

RQ1、RQ2 的任务是**找出并收窄变量**，不一定需要对照实验；严格的自变量、因变量比较集中在 RQ3。
