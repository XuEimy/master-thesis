## 研究基线

暂定题目：《面向个人回忆唤起的 AI 辅助生活记录与表达设计研究》。研究关注个人对自身经历的回忆：哪些线索需要保留，怎样记录才适合个人习惯，以及 AI 如何辅助整理、表达与再次呈现。

本项目从 2026-10-23 重新建立。旧项目的名称、研究框架、文献结论和设备方案不自动继承。旧开题稿仅用于比较展开程度和工作量；参考图只可借用视觉结构，不可直接套用研究内容。

## 已确认的研究边界

- 这是跨学科硕士论文，不限于 HCI；跨领域检索后按三个研究问题收敛整理。
- 个人回忆线索、适合个人习惯的记录策略、AI 辅助回忆与呈现构成三个相互关联的问题。
- 区分文献事实、综合推论、拟议设计与验证结果。文献综述草稿完成不意味着全部原文已核读。
- 区分观看意愿、表达体验、回忆发生、细节与可核对事实。材料内容、本人回忆、事后补述和 AI 新增内容不能混为一谈。
- 硬件不能仅由记录需求直接推出。记录方式、输入组合与硬件应结合个人习惯、情境、后续处理要求和工程可行性共同迭代。
- 不预设一天、全天连续拍摄、具体设备、生成形式、样本量或实验时长。实验是完成研究任务的方法。
- 候选框架和技术路线仍待研究及评议，不能宣称已验证或创新已成立。

**起因。** 用户表示研究背景之后的内容读不明白。重读导师指导后，用户确认导师的核心要求是：先说清楚该记录什么、这些内容为什么能引起回忆，并且要有依据。原第二章的 60 篇引用基本只核读到摘要层级，且由代理阅读；第三、四章建立在这一基础上。因此用户决定**亲自精读关键论文**。代理负责提供清单、精读卡模板和原文，在用户读后参与讨论、追问；不先替用户总结论文，未经要求不代写章节正文。

**研究推进逻辑**（用户提出，经讨论修正）：

```
精读 → 精读卡（理论框架；实验研究的自变量、因变量、结论）
     → 第二章：理论基础 + 三个问题的实证 + 变量汇总 + 缺口
     → 初步框架 → 第三章：从框架中选出要检验的关系 → 子问题 → 方法
     → 形成性调研修正框架 → 原型 → 预实验 → 正式比较 → 修订框架
```

讨论中确定的四点修正：

1. 只有实验研究才有严格意义的自变量和因变量。理论、质性和设计研究要按各自类型提取内容。
2. 先提出初步框架，再从框架中选出要检验的关系，不是先选变量。
3. RQ1、RQ2 以探索、收窄变量为主；严格的对照比较集中在 RQ3。
4. 访谈只能修正框架，不能证明框架成立；要证明某种做法更能引起回忆，必须做比较。

预实验之后，研究还需要原型和正式比较，论文才算完成。规模可以收窄，具体在开题时与导师确认。
