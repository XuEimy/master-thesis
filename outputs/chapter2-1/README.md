## 问题与来源

1. 个人回忆是什么，又怎样形成？[Conway 与 Pleydell-Pearce（2000）](https://pubmed.ncbi.nlm.nih.gov/10789197/)的自我—记忆系统及 [Rubin（2006）](https://pubmed.ncbi.nlm.nih.gov/26151796/)的基本系统模型。分别绘制，不将两套理论合并成一个未经提出的模型；基本系统仅列部分。
2. 照片和数字材料怎样参与回想？[Harper（2002）](https://doi.org/10.1080/14725860220137345)的照片引谈方法及 [Hutmacher 等（2025）](https://doi.org/10.1186/s41235-025-00627-4)的 41 人思维出声研究。区分方法贡献与观察结果，保留随机日使用资源与切换更多的任务条件。
3. 影像怎样组织经历并表达个人意义？[Rosas 与 Dittus（2021）](https://doi.org/10.1080/17503280.2020.1815123)对三部自传纪录片的分析。说明档案重新语境化、蒙太奇及自我表达，不推定改善回忆能力。

## 本次核验

前两篇核对 PubMed 摘要；Hutmacher 核对出版社摘要及研究说明；Harper、Rosas 出版社页面直接打开受限，核对出版社搜索索引摘要并与项目引文核读记录交叉核对。没有新增五篇全文审计。图示为文献内容的概念重绘，不是论文原图；箭头不统一表示因果。未加入本论文实验、AI 方案或后续任务。
