# 06 拍摄影响的相反结果如何连接

**连接问题：记录会支持回忆，也可能改变当时的注意；怎样保留这些差异？**

这组文献应先按“拍摄时的编码—当下的体验—日后的回看”分开，再比较任务。当前多数为摘要核读；Soares 与 Storm（2022）的正文已核读，具体统计及原始数据尚未复核。

| 文献节点 | 拍摄与测量方式 | 当前可连接的结果及边界 |
|---|---|---|
| [Henkel，网络首发 2013／卷期 2014](https://doi.org/10.1177/0956797613504438) | 博物馆中按指令观察或拍摄；另有聚焦局部操作 | 完整拍摄出现记忆受损，聚焦局部未呈现相同受损；拍摄方式需要进入解释 |
| [Barasch 等，2017](https://doi.org/10.1177/0956797617694868) | 自主拍摄；不回看照片，分别测视觉与听觉再认 | 视觉结果更好、听觉结果更差；不能把两者合成“总记忆提高” |
| [Soares 与 Storm，网络首发 2017／卷期 2018](https://doi.org/10.1016/j.jarmac.2017.10.004) | 限时照片或删除照片，改变之后能否访问的预期 | 受损仍出现，对单一认知卸载解释构成限制 |
| [Lurie 与 Westerman，2021](https://doi.org/10.1016/j.jarmac.2020.11.002) | 知觉型与概念型测试，不同延迟 | 两类测试均出现受损；仅凭测试分类还不能解释分歧 |
| [Soares 与 Storm，2022](https://doi.org/10.3758/s13423-022-02149-2) | 屏幕绘画；仅观察、拍一张、拍五张；组内与组间实验 | 五张条件的受损未被拍摄多样化消除；一张条件并非每项实验都显著 |

这是一条从结果差异逐步追问机制的研究线。自主选择拍摄对象、按要求操作、聚焦细节、拍摄数量和后来是否能看照片，都是需要对齐的条件。跨论文出现不同方向，尚不能自动证明其中某一个条件就是差异的原因；仍需针对性操纵或更完整的方法比较。

另一路研究的结果是**体验享受**。Diehl 等发现拍摄可通过增加投入改变体验评价，并讨论体验本身的投入程度、拍摄干扰及情绪性质。Nardini 等进一步研究高度愉悦经历中拍摄可能带来的损失。二者应按适用情境比较，不能拿享受评分代替记忆效果。[Diehl 等，2016](https://doi.org/10.1037/pspa0000055)；[Nardini 等，2019](https://doi.org/10.1002/mar.21194)

拍摄目的又连接到分享。Barasch 等研究的是拍摄时已经打算给他人看的目标；Vasquez 等研究的是选择性分享照片之后的记忆。前者的自我呈现顾虑和享受下降，与后者某些照片细节的记忆优势，可以同时成立，因为时间环节和结果不同。[网络首发 2017／卷期 2018](https://doi.org/10.1093/jcr/ucx112)；[2025](https://doi.org/10.1017/mem.2025.3)

Diehl 与 Zauberman 的近年综述，以及刘红艳等的中文综述，可作为追溯这些机制与边界的入口。使用综述后仍需核对原始研究，尤其不能把未测量的感官或结果补入单个实验。[2022](https://doi.org/10.1016/j.copsyc.2022.101334)；[2023《消费者拍照行为影响消费体验的双刃剑效应》](https://doi.org/10.3724/SP.J.1042.2023.00480)

**与选题的连接是一个待验证问题：**个人参与记录的方式如何影响当下注意，又如何与之后利用记录回忆配合？自动化程度、参与感和回看收益需要分别评价。相机记录更多信息，不能单独回答这三个问题。
