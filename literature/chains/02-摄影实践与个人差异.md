# 02 摄影实践与个人差异

**连接问题：适合个人的记录方式，为什么不能只按设备或拍摄参数划分？**

van Dijck 将个人摄影放在记忆、沟通和身份的交织关系中；Keightley 与 Pickering 进一步从拍摄、存储、观看、分享的实践讨论技术变化。这两项研究使“记录习惯”扩展为材料在生活中的整个使用过程，而不是仅统计拍照次数。[van Dijck，2008](https://doi.org/10.1177/1470357207084865)；[Keightley 与 Pickering，2014](https://doi.org/10.1177/1461444814532062)

Van House 对日常摄影的研究连接了记忆、关系、自我呈现和自我表达。它提示访谈需要理解同一张照片承担的多种作用。这里的连接是实践解释，不意味着这些动机已形成可直接用于算法的人群标签。[2011](https://doi.org/10.1080/1472586x.2011.571888)

Fawns 的 blended memory 框架将摄影史与分布式回忆连接起来；其后 Cued recall 通过照片诱导访谈，细分从初始想起到联想、推断和意义建构的活动。因此，同一张照片的作用可能取决于如何遇见、怎样翻看、与什么一起出现及过去如何使用。两文可能使用重叠研究材料，须核实后才能计算独立研究数。[网络首发 2019／卷期 2020](https://doi.org/10.1177/1750698019829891)；[网络首发 2022／卷期 2023](https://doi.org/10.1177/17506980211073093)

摄影视角研究提供更具体的连接。Niese 等考察捕捉意义与身体体验两类目标，讨论第一、第三人称照片的选择与观看偏好。King 等则发现含本人照片与观察者式回忆视角相关。前者涉及摄影目标，后者涉及回忆视角，两者共同说明“拍什么视角”需要明确想支持的体验；不能由它们推出统一最佳视角。[Niese 等，网络首发 2023／卷期 2024](https://doi.org/10.1177/19485506231163012)；[King 等，网络首发 2023／卷期 2024](https://doi.org/10.1002/acp.4150)

Finley 与 Brewer 的可穿戴相机研究又把关注点带回日常回忆：参与者先自由回忆，再借照片修正或补充。这提供了一种观察照片如何改变回忆内容的方法，但小样本和自评准确性限制了结论。[2024](https://doi.org/10.1080/09658211.2024.2377193)

**由此形成的待验证连接：**个人摄影目标与既有实践 → 对记录内容和视角的需求 → 回看中的线索使用方式 → 不同回忆结果。上述文献支持分别研究各环节，尚未共同验证整条因果链。
