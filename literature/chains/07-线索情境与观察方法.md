# 07 线索、情境与观察方法

**连接问题：什么线索有效，取决于线索本身，还是线索与当前活动、个人经历的关系？**

从 Conway 与 Pleydell-Pearce 的自我记忆系统出发，Berntsen 的后续评价把直接提取视为需要精确操作化的理论概念，并指出旧模型的解释限制。2021 年综述将自发回忆与情境特征重叠、较少的执行控制联系起来。这使“什么时候出现内容”与“出现什么内容”成为可以一起研究的问题。[2000 模型](https://doi.org/10.1037/0033-295x.107.2.261)；[2021 综述](https://doi.org/10.1098/rstb.2019.0693)；[网络首发 2023 的理论评价](https://doi.org/10.1080/09658211.2023.2294690)

Vannucci 等操纵警觉任务中的线索频率与负荷，发现较多线索未带来较多报告的自发回忆。它提供了“线索密度—当前负荷—觉察及报告”的实验入口；从这里到日常提示频率仍有外推距离。[2015](https://doi.org/10.1007/s00426-014-0632-y)

Congleton 等进一步研究视空间与听觉线索，以及编码时关注和提取线索的匹配。不过参与者回想的是刚观看的影片，所以结果不能直接成为个人生活记录中声画配比的标准。[2021](https://doi.org/10.1007/s00426-020-01304-5)

Tullis 与 Finley 对自生线索的讨论引入个人化：本人能利用自己特有的知识和经历建立联系。它与“AI 根据图像显著性选择线索”之间并非已经等价；本论文需要比较本人选择、本人命名、系统识别及协商后的线索。[2018](https://doi.org/10.1177/2372732218788092)

走进日常情境后，观察方法本身成为关键。Clevinger 与 Mace 显示“全部记录”“任选两条”“最先两条”的日记规则会改变线索分布；Mace 等发现对抽象线索的识别和报告与心理学训练背景有关。因此，访谈中用户提到某种线索较多，既可能反映实际经验，也可能反映采样规则和理解方式。[2024 日记方法比较](https://doi.org/10.1002/acp.4225)；[网络首发 2014／卷期 2015 的个体差异研究](https://doi.org/10.1080/09658211.2014.900083)

Laughland 与 Kvavilashvili 的驾驶记录研究提供动态线索和回忆链的观察例子，但它来自第一作者一个人的重复行程。它适合提出情境问题，不适合估算一般人的回忆频率。[2024](https://doi.org/10.1080/09658211.2023.2296826)

日常线索日记研究与新近开放式怀旧线索调查则帮助扩展候选内容：物件、地点、活动、音乐、食物等均值得考虑。前者记录回忆线索，后者询问怀旧，两种现象须分别编码。[Things That Make Us Reminisce，2015](https://doi.org/10.1145/2702123.2702460)；[What makes you feel nostalgic?，2026](https://doi.org/10.1080/09658211.2026.2710049)

**候选研究连接：**个人经历与线索之间的关系 → 遇见线索时的情境和负荷 → 是否觉察并开始回忆 → 如何报告这一过程。它需要多种方法相互补充，当前尚未确定最终变量和采样规则。
