# 文献串联库

2026-10-23 用户要求继续调研、扩大范围并完成完整文献综述。当前主入口是 [文献综述章节草稿](../docs/05-文献综述.md)：正文引用 60 项来源，含 58 项 DOI 文献和 2 项中文官方来源。既有 DOI 核读库扩展为 86 项；篇数是文献报告数，不是独立研究数。此前 32 项主链不再是当前范围上限。

[方法与核读边界](review/综述方法与核读边界.md) 说明检索覆盖、实际阅读层级和全文缺口；[引文与证据核对表](review/引文与证据核对表.md) 可逐项追溯。没有完成全部全文核读或订阅数据库内部穷尽检索。范围与证据规则见 [检索约定](检索约定.md)。

先从 [文献串联入口](chains/00-串联入口.md) 进入，再按需查看 [逐篇索引](data/已核读文献索引.csv) 和 [待获取原文](待获取原文.md)。

- `sources/`：各平台原始响应、精确检索式与分页证据。
- `data/`：规范化文献、去重与筛选记录、关联边和待获取队列。
- `cards/`：核读后逐篇文献卡。
- `chains/`：围绕研究问题的文献连接；每条边标明依据。
- `review/`：正文底稿、完整引用对应、补检日志及两项中文官方来源。
- `scripts/`：可恢复的采集、整理和校验脚本。

资料缺少原文不等于排除。获取层级及登录需求将单独标注。

原始平台响应、全文文件及大批未筛选记录目前保存在本机 `sources/` 与 `data/`，由 `.gitignore` 排除；Git 保存检索日志、脚本、核读节点、关系和获取状态。跨设备恢复原始缓存需重新运行相应脚本或另行迁移；不要把 Git 同步等同于全部全文备份。
