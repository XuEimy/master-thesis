# 文献串联库

本轮已按收紧后的三个研究问题形成可阅读的文献串联。主入口采用 32 篇有具体用途的依据，其余核读记录保留备查；尚未完成订阅数据库内部检索和全部全文核读，相关缺口单列。范围与证据规则见 [检索约定](检索约定.md)。

先从 [文献串联入口](chains/00-串联入口.md) 进入，再按需查看 [逐篇索引](data/已核读文献索引.csv) 和 [待获取原文](待获取原文.md)。

- `sources/`：各平台原始响应、精确检索式与分页证据。
- `data/`：规范化文献、去重与筛选记录、关联边和待获取队列。
- `cards/`：核读后逐篇文献卡。
- `chains/`：围绕研究问题的文献连接；每条边标明依据。
- `scripts/`：可恢复的采集、整理和校验脚本。

资料缺少原文不等于排除。获取层级及登录需求将单独标注。

原始平台响应、全文文件及大批未筛选记录目前保存在本机 `sources/` 与 `data/`，由 `.gitignore` 排除；Git 保存检索日志、脚本、核读节点、关系和获取状态。跨设备恢复原始缓存需重新运行相应脚本或另行迁移；不要把 Git 同步等同于全部全文备份。
