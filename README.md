## 核心问题

如何依据个人的记录习惯与回忆方式，设计 AI 辅助的生活记录和内容呈现方式，使日常经历中有意义的线索得以保留，并在适当情境下激发个人回忆？

当前检索与整理规则见 [聚焦搜索与串联策略](docs/04-聚焦搜索与串联策略.md)：多领域搜索，按三个研究问题收敛整理。

当前优先任务：提炼个人回忆线索及其记录需求，建立与 AI 识别、组织、生成和呈现之间的关系。
